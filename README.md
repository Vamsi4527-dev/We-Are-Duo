# We-Are-Duo

## Open the app on a phone

Start the development server with `npm run dev`. Vite prints a **Network** URL
(for example, `http://192.168.1.20:5173`); open that URL on your phone while
both devices are connected to the same Wi-Fi network.

If the page does not load, allow Node.js through your computer's firewall on
private networks and check that your Wi-Fi network allows devices to
communicate with each other.
